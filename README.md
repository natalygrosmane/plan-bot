# 🤖 Plan Bot — Персональный Telegram-ассистент по разгрузке головы

Автономный Telegram-бот для мгновенного сбора мыслей (текстом и голосовыми), планирования и структурирования задач.

Бот работает с тремя файлами в рабочем каталоге:
1. `inbox.md` — дневной сбор входящих мыслей.
2. `todo.md` — актуальные задачи и расписание (Top-3, Hard-события, утренние/дневные/вечерние блоки).
3. `backlog.md` — долгосрочные идеи и проекты по категориям.

---

## ⚡️ Возможности

- 🎙 **Голосовые и аудиосообщения**: бот расшифровывает голос (через Gemini, Groq Whisper или OpenAI Whisper) и сразу сохраняет суть в `inbox.md`.
- 📝 **Дневной сброс мыслей (Режим 1)**: отправляйте любые мысли — бот записывает их с меткой времени и тегами (`!задача`, `!рынок`, `!идея`) и отвечает предельно кратко (в одну фразу), не отвлекая.
- 🌙 **«Итоги дня» (Режим 2)**: бот читает инбокс, группирует всё по сферам (Трейдинг, Обучение, Ариана, Быт/Здоровье, Идеи), разделяет на жесткие/гибкие задачи и при утверждении переносит их в `todo.md` и `backlog.md`, очищая `inbox.md`.
- ☀️ **«Доброе утро» (Режим 3)**: выдает фокус на день — Top-3 задачи, дела по времени и гибкие задачи по блокам.
- 🔄 **«Ревизия недели» (Режим 4)**: воскресный аудит хвостов и правило 3-х недель для зависших задач.
- 🔒 **Приватность и безопасность**: бот отвечает только вам (`ALLOWED_USER_IDS`).

## 🚀 Быстрый старт

### 1. Создание бота в Telegram
1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot` и следуйте инструкциям.
3. Скопируйте полученный **API токен**.
4. Узнайте свой Telegram ID (например, через бота [@userinfobot](https://t.me/userinfobot)).

### 2. Настройка конфигурации
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Откройте `.env` и укажите:
```ini
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
ALLOWED_USER_IDS=ваш_telegram_id

# Провайдер для распознавания голоса и планирования: gemini, groq или openai
AI_PROVIDER=gemini
GEMINI_API_KEY=ваш_ключ_gemini
TIMEZONE=Asia/Bangkok
```

> **Совет по голосу:** Для быстрой и бесплатной расшифровки голоса отлично подходит **Gemini 2.0 Flash** или **Groq Whisper** (`GROQ_API_KEY`).

### 3. Запуск бота

Выполните скрипт запуска:
```bash
./run.sh
```
Скрипт автоматически создаст виртуальное окружение `.venv`, установит нужные библиотеки и запустит бота.

## 💡 Фоновый запуск (24/7)

Чтобы бот работал в фоновом режиме даже после закрытия терминала:

### Вариант 1: Через `nohup`
```bash
nohup ./run.sh > bot.log 2>&1 &
```
Остановить:
```bash
pkill -f "bot.main"
```

### Вариант 2: Через `pm2` (если установлен Node.js)
```bash
pm2 start run.sh --name "plan-bot"
```

| «Доброе утро» | Утренний фокус | Top-3 фокуса и расписание по блокам |
